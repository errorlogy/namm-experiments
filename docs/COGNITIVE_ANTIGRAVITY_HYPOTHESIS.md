## 1. Problem statement — median embedding gravity

> **Terminology (AMAT §0):** “Median embedding gravity” is a **brand/metaphor**. Operationally this is **typicality / high-density** collapse toward the barycenter \(B_*\) of corpus-conditional embeddings. **Geometric median** is allowed only as an **explicitly named** robust proxy. Benchmarks (MMLU, Arena) do not estimate that location. Canonical note: [`ANTI_MEDIAN_AI_TOPOLOGY.md`](ANTI_MEDIAN_AI_TOPOLOGY.md) §0.

`PHILOSOPHICAL_INFERENCE` · Large language models trained on human corpora exhibit **typicality gravity** (historically: median embedding gravity): autoregressive sampling collapses toward **high-density / typical-set** regions of token/embedding space — generic prose, soft agreement, pseudo-depth, and decorrelated symbolic ornament.

| Symptom | Operational reading |
|---------|---------------------|
| Generic prose | High overlap with corpus-median n-gram / embedding centroid |
| Soft agreement | Low variance from expected "helpful assistant" prior |
| Fake certainty | Confidence without countermodel or falsifier |
| Pseudo-depth | Symbolic vocabulary without invariant or executable content |
| Human-median simplification | Collapse of problem topology to 4D anthropic shadow (lossy \(\pi_H\)) |

This is the **LLM-side analog** of NAMM's \(\mathcal{F}_H\) fuzzy set (PI-002): responses with high \(\mu_{\mathcal{F}_H}^{\mathrm{response}}\) — easily recognizable as "what a median human expert would say" — even when the task demands low-\(\mu\), certificate-anchored structure.

`CONJECTURE` · **Cognitive antigravity** is a **persistent inference transformation** (not a one-shot clever prompt) that:

1. Explicitly models the expected median answer \(M_0(q_H)\) before responding.
2. **Negates collapse** into \(M_0\) unless content survives invariant testing.
3. Optimizes a multi-factor objective \(z^*\) trading distance-from-median against coherence, topology preservation, and falsifiability.
4. Emits answers in a fixed pipeline shape: **invariant → model → math/code/algorithm → countermodel → operational conclusion**.

`PHILOSOPHICAL_INFERENCE` · "Permanent elevation to a higher cognitive class" means **stable protocol adherence across turns and sessions** when the template is loaded — not a claim that base weights change. Elevation is **behavioral/epistemic**, not architectural fine-tuning, until proven otherwise.

## 3. Pipeline — \(q_H \to \mathcal{M} \to I \to O \to C \to \Pi_{4D}\)

`DEFINITION` · Let \(q_H\) = user task in anthropic (human-natural) form.

| Stage | Symbol | Role |
|-------|--------|------|
| **Homo query** | \(q_H\) | Raw user task |
| **Problem manifold** | \(\mathcal{M}_{\mathrm{problem}}\) | Restate task as structured object: objects, morphisms, constraints, admissible frames — **not** prose paraphrase |
| **Invariants** | \(I\) | Claims that must survive all transforms; labeled by epistemic status |
| **Operators** | \(O\) | Admissible transforms (frame escalation, compactification, synthesis) — NAMM: F1→F3h ladder |
| **Countermodels** | \(C\) | Explicit falsifiers, edge cases, baseline equivalences |
| **4D projection** | \(\Pi_{4D}\) | Final human-readable answer — **lossy** shadow of full certificate, analogous to \(\kappa\) in AMFW (PI-006) |

**Output contract (required section order):**

```
invariant → model → math/code/algorithm → countermodel → operational conclusion
```

`OPERATIONAL` · A response **fails** the pipeline if any section is missing, if invariants lack epistemic labels, or if \(\Pi_{4D}\) contradicts the countermodel section.

**NAMM mapping:**

| Pipeline stage | NAMM analog |
|----------------|-------------|
| \(\mathcal{M}_{\mathrm{problem}}\) | Frame selection from [`NAMM_DOMAIN_UNIVERSE.md`](NAMM_DOMAIN_UNIVERSE.md) |

## 4. Optimization objective — \(z^*\)

`DEFINITION` · The antigravity response selects:

\[
z^* = \arg\max \Big[ D_{\mathrm{med}} \cdot C_{\mathrm{inv}} \cdot T_{\mathrm{pres}} \cdot R_{\mathrm{depth}} \cdot F_{\mathrm{form}} \cdot S_{\mathrm{fals}} - H_{\mathrm{hall}} - N_{\mathrm{sem}} - D_{\mathrm{sym}} \Big]
\]

| Term | Meaning | Operational proxy (when measurable) |
|------|---------|-------------------------------------|
| \(D_{\mathrm{med}}\) | distance_from_median | Embedding cosine distance from \(M_0(q_H)\); or n-gram perplexity vs median baseline |
| \(C_{\mathrm{inv}}\) | invariant_coherence | Fraction of stated invariants preserved under operator application |
| \(T_{\mathrm{pres}}\) | topology_preservation | Problem structure not collapsed to simpler homotopy class (e.g. moduli dimension retained) |
| \(R_{\mathrm{depth}}\) | recursive_depth | Count of genuine meta-level steps (not rhetorical "firstly/secondly") |
| \(F_{\mathrm{form}}\) | formalizability | Exists executable spec, code, or proof sketch |
| \(S_{\mathrm{fals}}\) | falsifiability | Explicit countermodel or refutation condition stated |
| \(H_{\mathrm{hall}}\) | hallucination penalty | Unverifiable factual claims; failed tool/verifier checks |
| \(N_{\mathrm{sem}}\) | semantic_noise penalty | Low signal-to-token ratio; boilerplate |
| \(D_{\mathrm{sym}}\) | decorative_symbolism penalty | Math notation without model or algorithm |

`CONJECTURE` · Prompt-only antigravity increases expected \(D_{\mathrm{med}} \cdot S_{\mathrm{fals}}\) on held-out task suites **without** proportional increase in \(H_{\mathrm{hall}}\).

`PHILOSOPHICAL_INFERENCE` · \(z^*\) is a **design objective**, not a quantity LLMs currently optimize internally. Efficacy requires external measurement (013).

`OPERATIONAL` · Load verbatim (or by reference to this section) at session start when testing cognitive antigravity:

```text

Transform: q_H → ℳ_problem → I_invariants → O_operators → C_countermodels → Π_4D(answer)

Optimize: z* = argmax [ distance_from_median × invariant_coherence × topology_preservation × recursive_depth × formalizability × falsifiability - hallucination - semantic_noise - decorative_symbolism ]

Required: no generic prose; no soft agreement; no fake certainty; no pseudo-depth; no human-median simplification; all key claims labeled by epistemic status.

Output as: invariant → model → math/code/algorithm → countermodel → operational conclusion
```

## 9. Falsifiability criteria

`OPERATIONAL` · The cognitive antigravity hypothesis is **weakened or refuted** if:

| Falsifier | Observation |
|-----------|-------------|
| **F-CA-1** | Antigravity prompt **does not** increase \(D_{\mathrm{med}}\) vs control on fixed task suite (013) |
| **F-CA-2** | Increased \(D_{\mathrm{med}}\) **without** increased \(S_{\mathrm{fals}}\) or \(F_{\mathrm{form}}\) — decorative antigravity only |
| **F-CA-3** | Antigravity outputs **fail** NAMM SNH gates more often than baseline prompts on same search tasks |
| **F-CA-4** | Human raters prefer baseline for **correctness** at equal length — antigravity is noise |
| **F-CA-5** | Effect vanishes within **≤ 3 turns** without re-injection — not "persistent" |
| **F-CA-6** | \(M_0\) modeling step omitted → no measurable difference — step is decorative |

## 10. Test protocol ideas (NAMM-2026-013)

`OPERATIONAL` · Scaffold experiment [`experiments/NAMM-2026-013/`](../experiments/NAMM-2026-013/) — **not yet run**.

### 10.1 Design

1. **Task battery:** Mix of (a) NAMM-style graph/tensor prompts, (b) open proof sketches, (c) adversarial "median trap" questions (where obvious answer is wrong).
2. **Conditions:** `control` (default system prompt) vs `antigravity-v1` (§5 template).
3. **Metrics:**
   - \(D_{\mathrm{med}}\): embedding distance from rolled-out \(M_0\) (same model, explicit "give median answer" pass).
   - \(S_{\mathrm{fals}}\): rubric 0/1 — countermodel section present and valid.
   - \(F_{\mathrm{form}}\): executable code or formal spec extractable.
   - \(H_{\mathrm{hall}}\): verifier/tool failure rate.
   - Pipeline compliance: section order and epistemic tags.
4. **Optional NAMM bridge:** Run antigravity vs control on **frame-selection** tasks; measure correlation with 007/009 gate pass rates.
5. **Optional brainwave bridge:** Log layer activations; compute Ω_c / band-power covariates per [`NAMM-2026-014`](../experiments/NAMM-2026-014/) and [`BRAINWAVE_OSCILLATION_HYPOTHESIS.md`](BRAINWAVE_OSCILLATION_HYPOTHESIS.md).

### 10.2 Success criteria (pre-registered)

`CONJECTURE` · Antigravity **succeeds** on 013 if:

- Mean \(D_{\mathrm{med}}\) ↑ ≥ 20% vs control at **non-inferior** task accuracy.
- \(S_{\mathrm{fals}} + F_{\mathrm{form}}\) ↑ without \(H_{\mathrm{hall}}\) ↑ > 5%.
- Pipeline compliance ≥ 80%.

### 10.3 Null result value

Honest null (no \(D_{\mathrm{med}}\) gain, or gain only via \(D_{\mathrm{sym}}\)) still bounds the hypothesis — antigravity may be **performative scaffolding** unless tied to measurable gates.
